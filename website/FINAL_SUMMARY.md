## ✅ Prochaines Étapes

### 🚀 Étape 1 : Déploiement GoDaddy (1-2h)
1. Créer ZIP du dossier `website/`
2. Connexion GoDaddy → cPanel → File Manager
3. Upload dans `/public_html/`
4. Vérifier permissions (644/755)
5. Tester `https://coach-ryze.com`

### 🔒 Étape 2 : SSL/HTTPS (15 min)
1. cPanel → SSL/TLS Status
2. Run AutoSSL pour coach-ryze.com
3. Vérifier cadenas vert
4. Tester redirections HTTP → HTTPS

### 📧 Étape 3 : Emails (30 min)
1. Acheter Workspace Email GoDaddy
2. Créer les 4-5 adresses email
3. Configurer sur iPhone/Mac
4. Envoyer email de test

### 📸 Étape 4 : Screenshots (1h)
1. Prendre screenshots iPhone :
   - Dashboard principal
   - Scanner IA en action
   - Cardio GPS
   - Workout session
   - Widget iOS
2. Optimiser avec TinyPNG
3. Upload dans `/public_html/assets/images/screenshots/`
4. Modifier `index.html` pour utiliser vraies images

### 🎨 Étape 5 : Icônes (30 min)
1. Créer Apple Touch Icon (180x180)
2. Créer OG Image pour réseaux sociaux (1200x630)
3. Upload dans `/public_html/assets/images/`
4. Tester partage sur Facebook/Twitter

### 📊 Étape 6 : SEO & Analytics (30 min)
1. Google Search Console
   - Ajouter propriété coach-ryze.com
   - Valider avec HTML tag
   - Soumettre sitemap
2. Google Analytics 4 (optionnel)
   - Créer propriété
   - Installer code tracking
   - Vérifier événements

### ✅ Étape 7 : Tests Finaux (1h)
1. Test toutes les pages
2. Test responsive mobile/tablet/desktop
3. PageSpeed Insights (objectif > 90/100)
4. SSL Labs (objectif A+)
5. Vérifier tous les liens
6. Tester formulaire contact
7. Tester menu mobile

### 🎉 Étape 8 : Lancement (30 min)
1. Annoncer sur Instagram/Twitter
2. Mettre à jour bio avec lien site
3. Créer story avec QR code
4. Notifier bêta-testeurs (si applicable)
