Questions Fréquentes

Comment fonctionne le scanner IA de repas ? +

Le scanner IA utilise Google Gemini 2.0 pour analyser vos photos de repas. Il suffit de :

  1. Ouvrir l'application et cliquer sur "Scanner un repas"
  2. Prendre une photo de votre assiette
  3. L'IA détecte automatiquement les aliments et estime les portions
  4. Les valeurs nutritionnelles sont calculées en 5 secondes
  5. Vous pouvez ajuster les quantités si nécessaire

Note : Les estimations peuvent varier de ±20%. Pour plus de précision, vous pouvez éditer manuellement les portions.

L'application fonctionne-t-elle sans connexion internet ? +

Oui ! Ryze dispose d'un mode offline complet :

  • Workouts : Tous vos exercices de musculation sont disponibles offline
  • Cardio GPS : Le tracking GPS fonctionne sans internet
  • Nutrition : Vous pouvez ajouter des aliments depuis votre historique
  • Synchronisation auto : Dès que vous retrouvez une connexion, tout se synchronise automatiquement

Limitation offline : Le scanner IA et la recherche de nouveaux aliments nécessitent une connexion internet.

Comment installer le widget iOS ? +

Installation du widget smart sur iOS :

  1. Maintenez votre doigt sur l'écran d'accueil jusqu'à ce que les icônes tremblent
  2. Appuyez sur le bouton "+" en haut à gauche
  3. Recherchez "Ryze" dans la liste des widgets
  4. Choisissez la taille (Small pour Lock Screen, Medium pour Home Screen)
  5. Appuyez sur "Ajouter le widget"
  6. Positionnez-le où vous voulez

Astuce : Le widget détecte automatiquement le repas selon l'heure (petit-déj, déjeuner, dîner).

Les données nutritionnelles sont-elles fiables ? +

Nos données proviennent de plusieurs sources :

  • Scanner IA Gemini : Précision de ±20% (excellente pour la plupart des cas)
  • OpenFoodFacts : Base communautaire de 700 000+ produits (vérifiée mais peut contenir des erreurs)
  • Base interne : 50 000+ aliments vérifiés en FR/EN

Recommandations :

  • Vérifiez toujours les portions estimées par l'IA
  • Pour les produits scannés, comparez avec l'étiquette nutritionnelle
  • Vous pouvez éditer toutes les valeurs manuellement
  • Consultez un professionnel pour des besoins médicaux spécifiques
Comment définir mes objectifs caloriques ? +

Configuration de vos objectifs :

  1. Allez dans "Paramètres" → "Profil"
  2. Renseignez votre âge, sexe, poids, taille
  3. Choisissez votre objectif :
    • Perte de poids : Déficit calorique de 300-500 kcal/jour
    • Prise de muscle : Surplus de 200-400 kcal/jour
    • Maintenance : Équilibre calories consommées = brûlées
  4. Définissez votre niveau d'activité physique
  5. L'app calcule automatiquement vos besoins caloriques et macros

Ajustements : Vous pouvez modifier manuellement les valeurs si besoin.

Comment supprimer mon compte et mes données ? +

Conformément au RGPD, vous avez le droit de supprimer vos données à tout moment :

  1. Ouvrez l'application Ryze
  2. Allez dans "Paramètres" → "Compte"
  3. Faites défiler jusqu'en bas
  4. Appuyez sur "Supprimer mon compte"
  5. Confirmez la suppression

Conséquences :

  • Toutes vos données seront supprimées dans les 30 jours
  • Cette action est IRRÉVERSIBLE
  • Vous perdrez votre historique de progression

Alternative : Contactez-nous à support@coach-ryze.com pour une suppression manuelle.

Comment changer la langue de l'application (FR/EN) ? +

Ryze est bilingue natif français/anglais :

  1. Ouvrez "Paramètres"
  2. Section "Langue / Language"
  3. Choisissez "Français" ou "English"
  4. L'application redémarre automatiquement

Ce qui change :

  • Interface complète traduite
  • Base de données d'aliments adaptée
  • Exercices avec instructions localisées
