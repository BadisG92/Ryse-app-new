## 📝 Où Mettre Ces URLs dans App Store Connect

### Étape 1 : Connexion
1. Va sur [appstoreconnect.apple.com](https://appstoreconnect.apple.com)
2. Connecte-toi avec ton Apple ID Developer
3. Sélectionne **"My Apps"**
4. Clique sur **Ryse** (ou crée une nouvelle app)

### Étape 2 : App Information
1. Dans la sidebar gauche, clique sur **"App Information"**
2. Scroll jusqu'à **"General Information"**

### Étape 3 : Remplir les URLs

**Privacy Policy URL** :
```
https://coach-ryze.com/privacy_en.html
```
→ Champ : **"Privacy Policy URL"**
→ Obligatoire : **OUI** ✅

**Support URL** :
```
https://coach-ryze.com/support_en.html
```
→ Champ : **"Support URL"** (ou "App Support URL")
→ Obligatoire : **OUI** ✅

**Marketing URL** (optionnel mais recommandé) :
```
https://coach-ryze.com
```
→ Champ : **"Marketing URL"**
→ Obligatoire : **NON** (mais recommandé)

### Étape 4 : Informations sur l'Abonnement (si RevenueCat)

Si tu utilises l'abonnement (€9.99/mois après 7 jours gratuits), tu dois aussi :

1. Aller dans **"App Store"** → **"In-App Purchases"** ou **"Subscriptions"**
2. Créer/Éditer ton abonnement
3. Ajouter le **Terms of Service URL** :
```
https://coach-ryze.com/terms_en.html
```
