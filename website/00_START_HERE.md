## 🚀 DÉPLOIEMENT EN 3 ÉTAPES

### 1️⃣ Créer le ZIP (30 secondes)

```bash
cd /Users/badis/Documents/Ryse-app-new
zip -r website.zip website/ -x "*.DS_Store" "*.git*"
```

### 2️⃣ Upload sur GoDaddy (10 minutes)

1. [godaddy.com](https://godaddy.com) → Sign In
2. My Products → Web Hosting → Manage → cPanel
3. File Manager → `/public_html/`
4. Upload `website.zip` → Extract → Supprimer ZIP

### 3️⃣ Activer SSL (5 minutes)

1. cPanel → SSL/TLS Status
2. Run AutoSSL pour `coach-ryze.com`
3. Tester : `https://coach-ryze.com` ✅

### Site ne charge pas
👉 Vérifiez DNS : [dnschecker.org](https://dnschecker.org)
👉 Attendez 24-48h propagation

### HTTPS ne marche pas
👉 Attendez 5-10 min après SSL install
👉 Videz cache : Cmd+Shift+R

### CSS cassé
👉 Hard refresh : Cmd+Shift+R
