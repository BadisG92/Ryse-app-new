❓ Questions Fréquentes (FAQ)

🔄 Comment annuler mon abonnement Premium ?

Sur iOS :

  1. Ouvrez Réglages de votre iPhone
  2. Touchez [Votre Nom] en haut
  3. Sélectionnez Abonnements
  4. Touchez Ryze Premium
  5. Appuyez sur Annuler l'abonnement

⚠️ Votre abonnement restera actif jusqu'à la fin de la période déjà payée.

🗑️ Comment supprimer mon compte ?

Dans l'application :

  1. Ouvrez Paramètres (icône engrenage)
  2. Allez dans Mon Compte
  3. Faites défiler jusqu'en bas
  4. Touchez Supprimer mon compte
  5. Confirmez la suppression

⚠️ Cette action est irréversible. Toutes vos données seront définitivement supprimées :

  • Profil et préférences
  • Historique nutrition
  • Séances d'entraînement
  • Recettes sauvegardées
  • Graphiques de progression

📷 Le scanner IA ne fonctionne pas

Vérifiez que :

  • ✅ Permission caméra activée : Réglages → Ryze → Caméra → Activé
  • ✅ Connexion internet active (le scanner utilise l'IA en ligne)
  • ✅ Photo bien éclairée et nette
  • ✅ App à jour : Vérifiez sur l'App Store

Si le problème persiste : support@ryze-app.com

☁️ Mes données sont-elles sauvegardées ?

Oui, automatiquement :

  • ✅ Synchronisation cloud : Vos données sont sauvegardées en ligne si vous êtes connecté
  • ✅ Cache local : Mode offline disponible
  • ✅ Multi-appareils : Vos données se synchronisent entre vos appareils

Recommandation : Exportez régulièrement vos données :

Paramètres → Mon Compte → Exporter mes données

🔐 Comment réinitialiser mon mot de passe ?

  1. Sur l'écran de connexion, touchez Mot de passe oublié ?
  2. Entrez votre adresse email
  3. Vérifiez vos emails (et spam)
  4. Cliquez sur le lien de réinitialisation
  5. Créez un nouveau mot de passe

Aucun email reçu ? Vérifiez que l'adresse est correcte et contactez-nous.

🏋️ Comment ajouter un exercice personnalisé ?

  1. Allez dans l'onglet Sport
  2. Démarrez une nouvelle séance
  3. Touchez + Ajouter exercice
  4. En bas de la liste, touchez Créer exercice personnalisé
  5. Remplissez les informations et sauvegardez

💧 Comment activer les rappels d'hydratation ?

  1. Ouvrez Paramètres
  2. Allez dans Notifications
  3. Activez Rappels d'eau
  4. Personnalisez la fréquence (toutes les 2h recommandé)

🍽️ Les calories affichées sont-elles précises ?

Les données nutritionnelles proviennent de :

  • Scanner IA : Estimation par intelligence artificielle (~80-90% précision)
  • Base OpenFoodFacts : Données produits officielles
  • Votre saisie manuelle : Aussi précise que vos informations

Recommandation : Pour plus de précision, vérifiez et ajustez les portions après scan.

🌐 L'app fonctionne-t-elle hors ligne ?

Oui, partiellement :

  • ✅ Consultation de vos données
  • ✅ Ajout d'aliments manuels
  • ✅ Séances de musculation
  • ✅ Graphiques de progression

Non disponibles hors ligne :

  • Scanner IA (nécessite internet)
  • Scanner code-barres (nécessite internet)
  • Synchronisation cloud

Les données seront synchronisées dès la reconnexion.

  • 📸 Screenshots si possible
  • 🔄 Étapes pour reproduire le bug
