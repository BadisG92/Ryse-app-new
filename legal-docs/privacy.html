Politique de Confidentialité

Dernière mise à jour : 29 octobre 2025

Introduction

Bienvenue sur Ryze. Nous respectons votre vie privée et nous engageons à protéger vos données personnelles.

Cette politique explique :

  • Quelles données nous collectons
  • Comment nous les utilisons
  • Vos droits concernant vos données
  • Comment nous contacter

1. Données Collectées

1.1 Données de Compte

Lorsque vous créez un compte :

  • Email (pour authentification)
  • Nom et prénom (profil utilisateur)
  • Mot de passe (chiffré)
  • Méthode d'authentification (email, Google, Apple)

1.2 Données de Santé et Fitness

Vous fournissez volontairement :

  • Informations physiques : Poids, taille, âge, sexe
  • Objectifs fitness : Perte/prise de poids, maintenance
  • Entrées nutritionnelles : Repas, calories, macronutriments
  • Activités sportives : Séances de musculation, cardio, HIIT
  • Photos d'aliments : Pour analyse IA (stockées temporairement)
  • Enregistrements vocaux : Commandes workout (non sauvegardés)

1.3 Données de Localisation

Avec votre consentement :

  • Localisation précise pour tracking GPS des séances cardio
  • Localisation générale pour recommandations nutritionnelles régionales
  • Non utilisée en arrière-plan permanent

1.4 Données Techniques

Collectées automatiquement :

  • Identifiant appareil (pour synchronisation)
  • Système d'exploitation et version
  • Logs d'erreurs (pour améliorer l'app)
  • Données d'utilisation (fonctionnalités utilisées, fréquence)

2. Utilisation des Données

2.1 Fonctionnement de l'App

  • Afficher votre progression personnelle
  • Calculer calories et macronutriments
  • Générer recommandations IA personnalisées
  • Synchroniser vos données entre appareils
  • Tracker vos séances sportives avec GPS

2.2 Amélioration du Service

  • Analyser l'utilisation pour améliorer l'UX
  • Diagnostiquer et corriger bugs
  • Développer nouvelles fonctionnalités

2.3 Communications

  • Emails transactionnels (confirmation compte, reset password)
  • Notifications push (rappels workout, si activés)
  • Support client (réponse à vos questions)

2.4 Ce que nous NE faisons PAS

  • ❌ Vendre vos données à des tiers
  • ❌ Afficher de la publicité ciblée
  • ❌ Tracker votre activité sur d'autres sites/apps
  • ❌ Partager vos données santé sans consentement explicite

3. Partage des Données

3.1 Services Tiers

Nous utilisons ces services de confiance :

Supabase (hébergement données) :

  • Serveurs en Europe (RGPD compliant)
  • Chiffrement des données en transit et au repos
  • Politique : https://supabase.com/privacy

Google Cloud (analyse IA d'images) :

  • Images envoyées temporairement pour reconnaissance aliments
  • Supprimées immédiatement après analyse
  • Politique : https://cloud.google.com/privacy

Apple HealthKit (optionnel) :

  • Synchronisation locale uniquement
  • Vous contrôlez quelles données sont partagées

3.2 Exigences Légales

Nous pouvons divulguer vos données si requis par :

  • Ordonnance de justice
  • Enquête gouvernementale
  • Protection de nos droits légaux

4. Stockage et Sécurité

4.1 Localisation

  • Données principales : Serveurs Supabase (Europe)
  • Cache local : Stocké chiffré sur votre appareil

4.2 Durée de Conservation

  • Compte actif : Données conservées tant que compte ouvert
  • Après suppression : 30 jours (backup), puis suppression définitive
  • Données anonymisées : Peuvent être gardées pour statistiques

4.3 Sécurité

Mesures en place :

  • ✅ Chiffrement HTTPS pour toutes communications
  • ✅ Mots de passe hachés (bcrypt)
  • ✅ Authentification sécurisée (OAuth, Apple Sign In)
  • ✅ Accès restreint aux serveurs
  • ✅ Audits de sécurité réguliers

5. Vos Droits (RGPD)

5.1 Droit d'Accès

Vous pouvez demander une copie de vos données :

  • Allez dans Paramètres → Mon Compte → Exporter mes données
  • Ou email : privacy@ryze-app.com

5.2 Droit de Rectification

Modifiez vos données directement dans l'app :

  • Paramètres → Profil

5.3 Droit à l'Effacement

Supprimez votre compte et toutes vos données :

  • Paramètres → Supprimer mon compte
  • Ou email : privacy@ryze-app.com

5.4 Droit à la Portabilité

Exportez vos données au format JSON :

  • Paramètres → Exporter mes données

5.5 Droit d'Opposition

Refusez certains traitements :

  • Paramètres → Confidentialité
  • Désactivez emails marketing, notifications, etc.

6. Enfants

Ryze n'est pas destinée aux moins de 13 ans :

  • Nous ne collectons pas sciemment de données d'enfants
  • Si vous avez moins de 18 ans, demandez accord parental

7. Modifications

Nous pouvons modifier cette politique :

  • Notification par email pour changements majeurs
  • Date "Dernière mise à jour" en haut du document
  • Continuer à utiliser l'app = acceptation des modifications
