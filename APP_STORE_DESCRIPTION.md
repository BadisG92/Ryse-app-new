## STRATÉGIE ASO (App Store Optimization)

### Principe clé : Les mots dans le TITRE et SUBTITLE sont indexés par Apple
- Ne PAS répéter dans les keywords ce qui est déjà dans le titre/subtitle
- Utiliser les 100 caractères de keywords pour des mots DIFFÉRENTS
- Les 3 premières lignes de description sont cruciales (visibles sans "voir plus")
