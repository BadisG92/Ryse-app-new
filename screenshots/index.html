📸 Comment exporter en PNG ?

1

Ouvrir le screenshot en plein écran

Cliquez sur "Voir en plein écran" pour ouvrir le screenshot dans un nouvel onglet.

2

Utiliser un outil de capture

Option A - Chrome DevTools: Appuyez sur Cmd+Shift+P → tapez "screenshot" → sélectionnez "Capture full size screenshot"

Option B - Extension: Utilisez GoFullPage ou Fireshot pour capturer la page entière

Option C - En ligne: Utilisez htmlcsstoimage.com pour convertir directement

3

Vérifier les dimensions

L'image exportée doit faire exactement 1284 × 2778 px pour l'iPhone 6.5". Si besoin, redimensionnez avec Figma ou Photoshop.

4

Format pour l'App Store

Exportez en PNG ou JPG sans transparence. Nommez les fichiers: screenshot_1.png, screenshot_2.png, etc.
